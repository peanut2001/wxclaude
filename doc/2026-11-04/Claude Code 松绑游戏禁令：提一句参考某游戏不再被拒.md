链接复制成功

发布于：山东省

Anthropic 工程师阿迪·奥斯曼尼 11 月 4 日在 X 上宣布，Claude Code 2.1.317 已对 Claude Opus 5.5 的游戏开发限制做出调整。新规则允许用户在描述玩法与机制时直接点名现有游戏，Claude 不再因此甩手拒绝。这其实是被开发者"骂"出来的转向——就在上周，为防止有人拿 Claude Code 复刻他人作品，团队曾在 Opus 5.5 系统提示词里塞进两条硬规矩，要求回避复刻他人游戏。

误伤比抄袭更招恨，一条参考就触发拒单

那条规矩的毛病出在颗粒度太粗。不少开发者只是把某款游戏当玩法范例随口一提，Claude Code 便如临大敌，连带着整个开发任务一起拒掉。社区里"想做个类似 XX 的游戏"却被系统拦下的抱怨越来越多，逼得 Anthropic 重校这条红线。

新口径把"借鉴"和"复制"劈成两半：用户现在能大方提及某款现有游戏，请 Claude 参考其机制去做同类型原创；可一旦明确要求照抄原作，模型依旧会拒绝对直接复刻，转而推荐开发体验相近的新游戏。换言之，玩法思路可以"借光"，代码与美术的照搬仍被挡在门外。

对靠 AI 辅助做独立游戏的开发者，这算摸到了舒服的中间点——既保住版权护栏，又不再动辄误伤灵感。从强硬设防到柔性区隔，Anthropic 这次让步，是在"防抄袭"与"别添堵"之间找到的一条小路。[返回搜狐，查看更多](https://www.sohu.com/?strategyid=00001&spm=smpc.content-abroad.content.2.179386507906927dZOq1 "点击进入搜狐首页")
