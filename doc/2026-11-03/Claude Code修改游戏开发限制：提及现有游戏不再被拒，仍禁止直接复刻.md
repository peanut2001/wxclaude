凤凰网科技讯 北京时间11月4日，Anthropic工程师Addy Osmani在社交平台X发文宣布，已在Claude Code 2.1.317版本中调整Claude Opus 5.5的游戏开发限制，允许用户引用现有游戏描述玩法和机制，不再因此直接拒绝生成游戏。

![Image 5: 图片](https://inews.gtimg.com/news_bt/OkR4LaCOVgm79xVPz7u-scdJ19IDDjNqNVaE52eRPLZEAAA/641)

此前，Anthropic为防止用户利用Claude Code复制已有游戏，在Opus 5.5的系统提示词中增加了两条规则，要求模型避免复刻他人的游戏作品。这项限制于上周引发开发者不满，因为即使用户只是提及某款游戏作为玩法参考，Claude Code也可能拒绝执行开发任务。

Osmani承认，此前的限制过于宽泛，导致部分本应正常完成的游戏开发项目遭到拒绝。

针对这一问题，Anthropic已调整相关规则。按照最新说明，用户现在可以直接提及某款现有游戏，让Claude参考其玩法机制，开发同类型的原创游戏。 但如果用户明确要求复制原作，Claude仍会拒绝直接复刻，转而建议开发一款具有类似体验的游戏。

Osmani表示，Anthropic希望Claude能够尽可能帮助开发者创作原创作品，同时保护现有游戏开发者的知识产权，防止他人利用AI复制其成果。

这一调整也反映出AI编程工具在版权保护与创作自由之间面临的难题。随着AI模型的代码生成能力不断提升，开发者可以通过自然语言快速制作游戏，但如何区分借鉴玩法机制与复制现有作品，仍是AI工具需要解决的问题。

Osmani表示，Anthropic将继续完善相关限制，并邀请开发者反馈Claude错误拒绝开发其自有游戏项目的情况。(编辑/于雷）
